# Website UI kit

Interactive recreation of the Orange Jelly marketing site as specified in `10-website-blueprint.md` (no live site or Figma was provided; this is the blueprint made visible, using only copy from the brand pack).

- `index.html` — click-through shell: sticky header nav, footer, route state
- `Shared.jsx` — SiteHeader, SiteFooter, Wordmark, Eyebrow
- `Home.jsx` — full homepage per the blueprint's 9-section wireframe (hero, recognition, promise, pressure points, method, proof, fit, offers, final CTA)
- `HowWeWork.jsx` — method page: 4 stages, diagnostic contents, client responsibilities
- `Results.jsx` — The Anchor as live lab + proof-by-pressure-point cards with honest qualifiers
- `StartHere.jsx` — enquiry form (blueprint's recommended fields) with post-submit state

Growth problems hub, Insights and About are deliberate stubs: the pack contains no page-level copy for them yet.
