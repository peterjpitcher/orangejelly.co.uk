Colour-coded taxonomy that never competes with orange: each category is a muted secondary hue from the `--cat-*` tokens.

```jsx
<CategoryTag category="margin" href="/insights/margin" />
<CategoryTag category="hospitality" filled />
```

Categories: demand, conversion, margin, operations, experience, scale, hospitality. Use `filled` on cards over paper backgrounds; never restyle a category to orange.
