Action button; use `primary` (orange) for the single dominant CTA per view, `ink` for secondary, `ghost` for tertiary.

```jsx
<Button size="lg" arrow>Book a growth diagnostic</Button>
<Button variant="ink">Bring us the problem</Button>
<Button variant="ghost" size="sm" href="#method">See how we work</Button>
```

Hover shifts the block and adds the hard pressure shadow (ink variant gets an orange shadow). Sentence case labels only.
