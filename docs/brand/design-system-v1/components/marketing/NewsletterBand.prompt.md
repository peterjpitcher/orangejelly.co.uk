Ink email-capture band, usually the last section before the Footer on Insights and article pages.

```jsx
<NewsletterBand onSubmit={email=>subscribe(email)} />
<NewsletterBand title="One idea a month." blurb="A real growth problem pulled apart, with the numbers." buttonLabel="Send it" />
```

Defaults carry approved copy, so it works with no props. Don't show it and a StickyCTA on the same page.
