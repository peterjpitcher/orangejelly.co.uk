## Rollback

**Trigger:** any redirected URL returning a 404 or a chain, the enquiry form
failing to write a contact row, or an uncaught error on `/`, `/start-here`
or `/results`.

**Action:** revert the release commit and redeploy. It is one commit, and it
contains only the phase flip and the deletions, so the revert restores both
the old pages and the old redirect table in a single step. Nothing in the
release writes to the database, so there is no data to unwind.

**Not a trigger:** a ranking movement. Consolidation moves rankings around for
weeks, and reverting on day two would cost more authority than it earned.

**Owner:** Peter Pitcher. Single responder, single mailbox
(`peter@orangejelly.co.uk`). Reachable for 48 hours after the release.

**Window:** deploy on a weekday morning, never on a Friday and never before a
day nobody is available.
